# rock-paper-scissors-project

This is my solution to The Odin's Project exercise "Project: Rock Paper Scissors".

## Task

Create a Rock Paper Scissors game that is played against the computer with a prompt and on the console.

## Languages

JavaScript - to practice functions, different methods and if statements.
HTML - blank page with prompt

## Reflection

This project was a goo all-rounder to practice what I've learned in the course so far.

At the beginning, I felt quite intimidated, not sure if I would be able to do it. But as I moved on in the exercise and I could complete the tasks, the more my confidence grew.

Step 6 was a bit harder for me and had to research for some of the errors I kept getting, mostly due to the fact I had the 2 const still in the global scope. Once they were moved inside the function's scope, everything seemed to work.
